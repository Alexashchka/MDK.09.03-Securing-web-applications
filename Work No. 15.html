Практическая работа №15

Тема работы

Название: Аудит веб приложений. Отчёт об ошибках

Цели и задачи

Задачи:

  • изучить для чего используется технический аудит сайта;
  • научиться проводить технический аудит для сайта;
  • приобрести навыки в безопасности сайта.

Видео выполнения практической работы

Появится в скором времени.

Теоретический материал

Представлено в виде лекций.

Порядок выполнения работы

Согласно своему варианту (уточнить у преподавателя), провести аудит веб-приложения, на наличие следующих уязвимостей:
- наличие XSS-инъекций;
- наличие SQL-инъекций;
- наличие CSRF-инъекций;
- наличие журнала логирования;
- сложность используемых паролей;
- наличие токена авторизации;
- использование recapture;
- наличие шифрования передаваемых данных и чувствительной информации;
- наличие механизмов для загружаемых файлов;
- наличие механизмов блокировок пользователя.

Варианты: тык.
Оформить отчёт.

Контрольные вопросы

1) Какую ещё защиту можно выполнить, чтобы избежать загрузку вредоносных файлов?
2) Какие вредоносные файлы существуют кроме PHP?

Дополнительное задание

Для получения оценки «Отлично», реализовать восстановление к заблокированной записи по контрольному вопросу, заданному при регистрации.
